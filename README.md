# Centre Dentaire ANOUAL — Website

Premium responsive dental clinic website built with **Next.js, TypeScript, Tailwind-style CSS, Lucide icons and Framer Motion**.

## Included
- Responsive one-page website
- French content
- Framer Motion scroll reveals and hover animations
- Mobile navigation
- Appointment phone CTA
- WhatsApp CTA
- Google Maps CTA
- Services, doctors, testimonials, opening hours and contact sections
- SEO metadata

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm start
```
